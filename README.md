# Robot

网页手动驾驶默认使用四轮独立转向：前进/后退按线速度行驶，左转/右转按角速度转向；同时按住行驶与转向方向可边行驶边转弯，单独按转向则原地旋转。支持方向键组合、页面多指按钮及两者混用，松开一个方向后继续执行仍按住的方向。

实机底盘已增加三控制板独立通信、真实反馈年龄诊断和自动平衡防过冲控制；控制管理器以 20 Hz 交换缓存，腿板默认 10 Hz、轮板 6 Hz，SE2 默认每 20 ms 刷新并按真实发送间隔监测，串口日志异步发布；实际提速需按分阶段验收确认。参数、基线采集与回退方法见 [通信与平衡优化](ROS2/docs/balance_optimization.md)。
驾驶输入已增加独立持续连接，并以驾驶确认单独判断连接状态，避免状态查询超时清空按键；自动平衡中档改为依据实际腿角和 IMU 直接发送完整到位位置，并抑制微小目标重复下发，保持区采用 1° 进入、1.5° 退出的滞回；腿板按通道去重，未变化的到位目标不重复启动。参数和验收边界见 [通信与平衡优化](ROS2/docs/balance_optimization.md)。


机器人项目仓库，按控制平台分为 ROS 2 工作区和 STM32 控制板工程：

```text
Robot/
├── ROS2/   # ROS 2 Jazzy 工作区，src、scripts、docs 等目录直接放在这里
└── STM32/  # 两套 STM32 控制板工程
    ├── Sevo_Echo_F103_V2/
    └── motor2_stm32f401rct6_mini/
```

当前实机默认使用 Astra Pro RGB-D（已替换原头部双目），安装中心与高度沿用原头部 xacro，安装 TF 已启用；部署和坐标说明见 [Astra Pro 接入](ROS2/docs/astra_pro.md)。

Docker 同时支持保留原双目 `/dev/stereo_camera → /dev/video0` 映射，并新增 Astra `/dev/bus/usb` 访问；双目需在创建容器前接入。

ROS 2 工作区的功能介绍、构建和运行方法见 [ROS2/README.md](ROS2/README.md)。

三路里程计已增加迟到视觉的历史回放和过龄/无效视觉保护；短时单路断流可继续推算，但四轮一致打滑、全部断流及高度失去观测仍有漂移风险。检查结论与隔离测试见 [里程计融合检查](ROS2/docs/odometry_fusion_audit.md)。

实机已有地图默认使用视觉与 AMCL 联合定位，当前实机由 Astra Pro 同时提供彩色视觉、深度和定位点云，保留可配置来源及旧双目回退。两路一致时保守融合，冲突优先通过质量检查的视觉结果，统一发布地图修正而保留连续 `/odom`。支持切回原视觉模式或仅二维地图的 AMCL 模式，使用方法和验收边界见 [联合定位](ROS2/docs/joint_localization.md)。

从仓库根目录构建时：

```bash
cd ROS2
colcon build --symlink-install
source install/setup.bash
```

实机硬件插件在 `/hardware/serial_tx` 发布三块控制板每次实际串口写入及事务结果；
日常默认不录制此串口流水，专项排查时在录制话题配置的“按需”分类启用；历史索引仍单独配置。
日常录制与历史索引分别由 `robot_logging/config/recording_topics.yaml` 和 `index_topics.yaml` 控制，均按常用、按需、不建议分类并逐项开关。默认录制保留导航、定位和硬件排障信息，索引只保存关键日志、状态变化及每秒导航反馈；索引满后滚动淘汰旧查询行，原始 MCAP 仍按录制保留期和总配额管理。网页导航目标及失败原因通过 `/web_console/navigation_status` 纳入日志。

机器人控制台位于同一 9100 端口的 `/robot/`，提供手动驾驶、地图导航、相机与目标、
探索与跟随、状态和 `/robot/console` 实时终端输出。`/log/` 继续作为独立的历史日志查询页。
状态页逐项显示转向、轮速、头部、四腿控制器、三块控制板和每路超声波；整车启动时控制台先于硬件与导航启动，地图未到达时会显示等待原因并重试静态地图服务。
地图导航视图随地图扩大和窗口变化自动显示全图；“居中机器人”保持当前缩放比例并持续以机器人为中心，“显示全图”恢复地图居中。机器人、目标及车头箭头按固定屏幕尺寸显示。地图支持以鼠标位置为中心的滚轮缩放、按住左键拖动平移及点击选点，拖动不会误选目标；手动查看局部时保留世界坐标视野，点击“显示全图”或“居中机器人”恢复自动视图。
已有地图联合定位要求每路独立完成三次有效确认，合格的视觉或轮廓来源可支撑定位；两路都暂缺时才使用现有 `/odom` 有界跟踪。默认最多 120 秒、累计 5 米或累计转角约 360°，先到上限即停车；里程计须新鲜、协方差合格且 TF 有效。定位输入整体中断默认容忍 20 秒，持续超时或里程计/TF 失效时撤销许可，恢复后重新确认。联合模式阈值在 `robot_navigation/config/global_localization.yaml`，原视觉模式仍使用 `map_localization.yaml`；网页显示当前来源、轮廓吻合度、拒绝原因与跟踪预算。低质量视觉不会因视觉优先而覆盖有效定位。

实机长期保存地图时会将二维地图、点云和 RTAB-Map 数据库成套保存；重载已有地图默认启动视觉与轮廓联合定位，网页可设置初始位置和朝向，并显示定位进度。未定位、定位超时或丢失时禁止自主导航，保留手动恢复；定位恢复后须重新规划确认。只有二维地图时可使用 amcl 模式；visual/fused 模式仍需配套数据库。

在线建图默认使用持久库 `/workspace/mapping/rtabmap.db`，重启保留原库；新建地图请显式指定新的 `mapping_database_path`。RTAB-Map 异常退出后自动从原库或 `.back` 的副本恢复保存地图，网页保存按钮也支持退出后恢复；整个容器退出时可运行独立恢复入口。已启用相似静止观测合并、工作内存节点转长期库及按需重载，操作与内存排查说明见 [地图异常恢复](ROS2/docs/mapping_recovery.md)。
长期地图目录和文件默认归当前用户所有（容器 root 自动识别工作区用户），目录 755、文件 644，当前用户可直接读写；可在快照配置中显式指定 UID/GID。
网页保存数据库时显示等待并禁用重复点击；保存请求独立等待 120 秒，响应超时与控制台离线会分别提示，超时后应先检查保存结果。
已有地图视觉定位使用历史原图重提取、均匀配准特征及双向交叉匹配，保持几何内点和连续确认要求；冷启动等待实际双目处理就绪后才发送初始估计。已知摆放位置可用 `initial_pose_enabled:=true` 配合 `initial_x/initial_y/initial_yaw`，网页回填估计供核对，人工修改优先。
静态地图服务增加生命周期自动恢复：启动超时后按实际状态继续配置或激活，已激活时不重复操作；持续失败降低重试频率，状态发布在 `/mapping/map_server_recovery/status`。
已有地图启动参数必须使用 ROS 当前运行环境可读取的路径；容器内地图通常位于 `/workspace/maps/`，错误路径会在整车启动前直接报出。
地图下方始终显示 Nav2 最新距离、目标朝向差、恢复次数与最终结果，切到手动模式仍可查看失败原因。取消立即撤销导航速度许可，等待 Nav2 目标终态后才显示取消完成；提交期间迟到的目标也会取消，切换模式不会恢复旧目标。失败优先显示 Action 原始错误，空结果补充本次 Nav2 错误日志；没有具体信息时明确标注未知原因。
网页画面区分正常、短时延迟和持续断流（默认 2 秒/20 秒）；画面显示状态不直接决定导航许可。导航失败收集 Nav2 主/子节点的具体 WARN/ERROR，并允许结果后 2 秒内补全迟到原因，首次失败不会被后续定位告警覆盖。Nav2 的 default_server_timeout 按毫秒配置为 2000；异常录制默认也遵守精简白名单，原始图像专项采集须显式开启 incident_record_all。
网页入口与控制台节点、页面、配置均位于 `ROS2/src/robot_web/`。

手动控制新增“车身姿态”和“头部”面板：四腿竖向滑块及精确输入显示板端角度（±15° 对应 R 字段 ±1500），手动提交直接设置角度目标；滑块向上仍代表伸展，左前/右后上滑角度减小，右前/左后上滑角度增大；自动平衡开关、低/中/高档和中档姿态目标位于车身姿态面板。键盘默认开启：方向键驾驶，W/S 前后倾、A/D 左右倾、Q/E 整体降低/升高（按钮和键盘每步最大 5°，按住每 0.3 秒重复），J/L 左右转头、I/K 抬头/低头，空格停止当前手动运动。倾斜只伸展对侧腿，整体升降保留高度差，按先到限位的腿共同限幅；允许驾驶同时调腿。平衡开启时禁止手动大腿，建图/定位锁定期间禁止手动头部。“四腿回零”仅一次提交四条大腿的 0° 目标；“头部回零”仅一次提交水平/俯仰两关节的 0° 目标，两组互不回零。
所有页签共用侧栏“紧急停止”：停止驾驶、平衡及手动关节，解除后不恢复旧动作；建图/定位头部归中须另点“恢复建图/定位头部归中”。状态页显示六个关节及其他轮子/转向关节反馈、四腿/四轮电流、平衡与限位，并分别显示 Astra 原始彩色、原始深度和处理后深度；状态有效性结合反馈时效及硬件故障，不用节点存在代替设备正常。新功能尚待架空与接地实机验收。
网页手动速度无需连接心跳和网页限速，直接送到底盘运动控制器；导航速度仍经避障层。
整车启动时八个 ros2_control 控制器逐个限时激活；若轮速等控制器最终无法激活，启动会明确报错退出，避免网页可转向但轮子无驱动的半启动状态。可用 `ros2 control list_controllers` 核对 `wheel_controller` 为 `active`。
实机超声波板偶发返回 0 时，ROS 硬件插件丢弃该次无效测距；连续无有效测距超过安全层超时后，导航速度仍会被拦截。
首页标题下方显示底盘故障和反馈中断提示。四轮行驶与停车统一发送 D4～D7 占空比命令，零速发送 D0；反向占空比取正向的负数，反馈由 D 状态查询和编码器差分计算。定距动作仍使用 T 命令。
网页直行默认线速度为 0.06 m/s，低/中/高预设分别为 0.06/0.08/0.1 m/s。全轮 D 模式只维护默认轮位标定文件，已完成 ±0.06/0.08/0.1 m/s 六段架空短测，四轮稳态误差 −11.8%～+1.7%，串口记录无 S 命令。
显式按下软件停止后，须在首页解除才能再次运动。
实机接地运动仍需先完成仿真和架空验收。启动与操作步骤见
[ROS2/README.md](ROS2/README.md)。

STM32 工程可分别用 STM32CubeMX/CubeIDE 或自带的 CMake 配置打开。每个工程的 `build/`
输出不纳入版本控制。
SE2（`Sevo_Echo_F103_V2`）固件启动时六路舵机 PWM 均输出 1500 µs；某路收到非中位命令后，
若 100 ms 内没有新命令，该路自动回到 1500 µs 并持续输出。显式发送 0 仍可关闭该路输出。
实机 ROS 硬件插件独立按 20 ms 刷新 SE2 六路 PWM；上游计算超过 400 ms 未更新时只发送中性值。控制管理器 20 Hz 交换缓存，轮板 6 Hz、腿板 10 Hz 独立通信，转向反馈超时为 0.4 s；真实 U 发送间隔达到 100 ms 仍锁定，不修改固件。
转向到位后输出中性 PWM，角度误差再次超过标定的重新调整阈值才恢复驱动；默认到位/重新调整阈值分别为 2.5°/4°，低于轮速放行的约 4.58° 门槛，在 ROS 舵机标定文件中配置。
