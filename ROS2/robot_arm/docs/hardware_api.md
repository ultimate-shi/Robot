# 机械臂关节控制板硬件API

协议版本：0.2。上位机连接master USB串口，选择115200、8N1，每条命令以换行结束；关节编号为1、2。运动前先完成标定，具体步骤见[通信、标定与固件测试](firmware_test_guide.md)。

## `$info`

作用：查询控制板身份和配置的关节列表；列表不代表从板在线。

格式：`$info`

示例：`$info` → `$info ARM 2 1 2`

## `$version`

作用：查询固件协议版本。

格式：`$version`

示例：`$version` → `$version 0.2`

## `R<id> <角度>` / `R <角度1> <角度2>`

作用：设置单个或两个关节的目标角度，由板端PID控制。角度相对标定零位，单位0.01°，范围−9000～9000；每条命令有效100ms，持续运动时约每50ms重发。

格式：`R<id> <角度>` 或 `R <角度1> <角度2>`

示例：`R 3000 -2000` → `R OK`，关节1目标+30°、关节2目标−20°。

## `R<id>` / `R`

作用：查询单个或全部关节状态，不延长运动有效期。全部查询最后返回`R END`。

格式：`R<id>` 或 `R`；状态响应为`R<id> <角度×100> <速度×100> <电流mA> <脉宽µs> <状态> <故障> <剩余有效期ms> <反馈龄期ms> <模式>`。

示例：`R1` → `R1 1250 300 NA 1528 1 0 76 2 1`，表示角度12.50°、速度3°/s，正在板端PID运行。

状态：0停止、1运行、2故障。模式：0无、1板端PID、2直接PWM。故障：0正常、1编码器异常、2未标定、3越限、4控制异常、5从板失联；6/7为过流/过温预留，尚未启用。`NA`表示数据不可用，电流目前未标定。

## `U<id> <脉宽>` / `U <脉宽1> <脉宽2>`

作用：直接设置单个或两个关节的PWM脉宽，绕过板端位置PID，可用于上位机PID。单位µs，范围500～2500，PWM频率固定50Hz；每条命令有效100ms，持续运动时约每50ms重发。

格式：`U<id> <脉宽>` 或 `U <脉宽1> <脉宽2>`

示例：`U1 1510` → `U1 OK`。1510仅为格式示例，实际使用需以已标定中立值为基准。

## `X<id>` / `X`

作用：停止单个或全部关节，输出配置的中立脉宽，清除运动目标；不是回零或断电。100ms到期也回到中立脉宽，若中立值错误，不能保证实际停转。

格式：`X<id>` 或 `X`

示例：`X` → `X OK`

## `A<id>`

作用：查询或设置零位原始值、编码器方向和电机方向。零位范围0～4095，方向为1或−1；设置先保存在内存，需用`$save`保存。

格式：查询`A<id>`；设置`A<id> <零位原始值> <编码器方向> <电机方向>`。

示例：`A1 2048 1 1` → `A1 OK`。2048和方向仅为格式示例，需按实际标定填写。

## `J<id>`

作用：查询或设置板端PID参考限速、参考加速度及停转中立值。速度单位0.01°/s，范围1～9000；加速度单位0.01°/s²，范围1～36000；中立值单位µs，范围500～2500。设置后立即持续输出中立脉宽，未知值不能依赖`X`或100ms超时保证停转；首次测量按测试文档进行。需用`$save`保存。

格式：查询`J<id>`；设置`J<id> <最大速度×100> <最大加速度×100> <中立脉宽µs>`。

示例：`J1 1000 3000 1500` → `J1 OK`，设置10°/s、30°/s²、中立1500µs；1500必须经实测确认。

## `P<id>`

作用：查询或设置板端PID参数，传输值为实际参数乘1000。Kp、Ki范围0～100，Kd范围0～10；需用`$save`保存。

格式：查询`P<id>`；设置`P<id> <Kp×1000> <Ki×1000> <Kd×1000>`。

示例：`P1 2000 0 0` → `P1 OK`，即Kp=2、Ki=0、Kd=0。

## `$zero`

作用：把当前有效编码器读数设为零位，先保存在内存；不设置方向，需用`$save`保存。

格式：`$zero <id>`

示例：`$zero 1` → `$zero 1 OK`

## `$save`

作用：将指定关节的A、J、P配置保存到Flash，断电后保留。A/J/P设置及zero/save在运行中拒绝执行。

格式：`$save <id>`

示例：`$save 1` → `$save 1 OK`

## `$clear`

作用：在标定、传感器和角度条件有效后清除故障，回到停止状态，不恢复旧运动目标。

格式：`$clear <id>`

示例：`$clear 1` → `$clear 1 OK`

## `$raw`

作用：查询原始传感器及标定标志，不改变配置。响应依次为编码器原始值、电流ADC、温度ADC、零位有效标志、中立值有效标志；原始值−1表示不可用，标志0为未设置、1为已设置。

格式：`$raw <id>`

示例：`$raw 1` → `$raw 1 1961 3611 4095 0 0`

## `$bus`

作用：通过USB查询当前连接板的UART总线累计计数，上电清零，不转发到其他板、不控制电机。rx为接收字节数，frame为CRC及封装有效帧数，bad为完整行的CRC或封装错误数，hit在slave上为寻址本板或接受的广播帧数、在master上为序号匹配的回包数，tx为UART发送并等待完成成功的帧数，txerr为发送失败数。wait为master最近等待的请求序号（slave为0），seen为最近解码成功的接收帧序号，mismatch为master收到有效帧但序号不匹配的次数。tx成功不代表对端已收到，查询时可能正有事务进行，wait与seen不要求始终相等。

格式：`$bus`

示例：`$bus` → `$bus rx=280 frame=20 bad=0 hit=20 tx=20 txerr=0 wait=20 seen=20 mismatch=0`

## `$busraw`

作用：通过USB查询本板UART最近收到的最多96字节，以十六进制按接收顺序输出；可能从一帧中间开始。用于排查有字节却无有效帧的情况，不控制电机、不清空UART或计数，无接收数据时返回EMPTY。

格式：`$busraw`

示例：`$busraw` → `$busraw 403432205232202A443836330A`，代表原始字节对应的文本`@42 R2 *D863`及换行。
