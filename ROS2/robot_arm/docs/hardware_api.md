# 机械臂关节控制板硬件API

协议版本：0.5。上位机连接master USB串口，选择115200、8N1，每条命令以换行结束；关节编号为1、2。主从板及工具必须配套升级；0.5状态调整为raw、角度、弧度、电流、PWM、状态、故障、模式，移除速度和两个时间字段，不兼容旧状态行。角度/PID支持有限十进制小数及科学计数，拒绝NaN、Inf、溢出和尾随垃圾。U直接PWM免标定，R角度控制先完成零位/方向标定，具体步骤见[通信、标定与固件测试](firmware_test_guide.md)。

## `$info`

作用：查询控制板身份和配置的关节列表；列表不代表从板在线。

格式：`$info`

示例：`$info` → `$info ARM 2 1 2`

## `$version`

作用：查询固件协议版本。

格式：`$version`

示例：`$version` → `$version 0.5`

## `R<id> <角度>` / `R <角度1> <角度2>`

作用：设置单个或两个关节的目标角度，由板端PID控制。角度相对标定零位，单位度，范围−90～90；发送一次后持续执行至到位或被新运动指令、X、故障打断。从板关节2还受总线失联停止约束，关节1不因从板离线停止。到位后是否保持由每轴H参数决定。

格式：`R<id> <角度>` 或 `R <角度1> <角度2>`

示例：`R 30.5 -20.25` → `R OK`，关节1目标+30.5°、关节2目标−20.25°。

## `R<id>` / `R`

作用：查询单个或全部关节状态，不延长运动有效期。全部查询最后返回`R END`。

格式：`R<id>` 或 `R`；状态响应为：

```text
R<id> <编码器读数> <角度°> <弧度> <电流mA> <脉宽µs> <状态> <故障> <模式>
```

示例：`R1` → `R1 1837 -10.9863 -0.191748 NA 1500 0 0 0`。编码器1837、相对零位角度约−10.9863°、弧度约−0.191748rad，当前停止、无故障。

编码器为AS5600单圈原始值0～4095，无需零位/方向标定；传感器无效、采样过期或从板离线时为-1。角度相对A设置的零位和编码器方向，弧度=角度×π/180；缺少有效零位/方向或反馈时两者均为NA。角度保留4位小数，弧度保留6位小数，不代表编码器物理精度。电流尚未校准，返回NA。

状态：0停止、1运行、2故障。模式：0无、1板端PID、2直接PWM。故障：0正常、1编码器异常、2未标定、3越限、4控制异常、5从板失联；6/7为过流/过温预留。未标定停止时可报告故障2，U不因此拒绝；U运行时不合成故障2。

0.5不返回速度、剩余有效期和反馈龄期，内部PWM100ms期限、编码器20ms有效期和slave看门狗仍有效。master查询R2或R中的从板状态会主动获取新回包，避免把下发目标前的缓存STOP作为新结果；内部仍限制采样与缓存总龄期，失联返回`R2 -1 NA NA NA NA 2 5 0`。R汇总的每轴均使用上述格式，结束行仍是R END。

角度是否到位由上位机结合角度、状态与模式判断。H=0时板端到位后STOP/NONE；H=1时保持RUN/POS，串口工具用连续角度观测估算速度并确认稳定，不再读取板端速度字段。OK仅表示接受命令，不表示到位。

## `U<id> <脉宽>` / `U <脉宽1> <脉宽2>`

作用：直接设置单个或两个关节的PWM脉宽，绕过板端位置PID，不要求零位、方向或中立标定。单位µs，范围500～2500，PWM频率固定50Hz；每条命令有效100ms，持续运动时约每50ms重发。编码器无效、真实故障保护仍有效；未完成方向和零位标定时不能保证基于方向的软限位制动。U1可在从板离线时独立执行；U2和双轴U仍要求从板在线，从板自身总线看门狗保留。

格式：`U<id> <脉宽>` 或 `U <脉宽1> <脉宽2>`

示例：`U1 1600` → `U1 OK`。停止和100ms到期回到中立，默认1500µs；OK只表示接受，不代表已实际转动。

## `X<id>` / `X`

作用：停止单个或全部关节，输出配置的中立脉宽，清除运动目标；不是回零或断电。PWM指令100ms到期也回到中立脉宽，默认1500µs，若中立值不适合实际舵机，不能保证物理停转。

格式：`X<id>` 或 `X`

示例：`X` → `X OK`

## `A<id>`

作用：查询或设置零位原始值、编码器方向和电机方向。零位范围0～4095，方向为1或−1；设置先保存在内存，需用`$save`保存。

格式：查询`A<id>`；设置`A<id> <零位原始值> <编码器方向> <电机方向>`。

示例：`A1 2048 1 1` → `A1 OK`。2048和方向仅为格式示例，需按实际标定填写。

## `P<id>`

作用：查询或设置板端PID参数，直接传输实际浮点数值。Kp、Ki范围0～100，Kd范围0～10；需用`$save`保存。

格式：查询`P<id>`；设置`P<id> <Kp> <Ki> <Kd>`。

示例：`P1 2.0 0 0` → `P1 OK`，即Kp=2、Ki=0、Kd=0。

## `H<id>`

作用：查询或设置本关节的到位保持参数。0到位停转，1到位保持；每轴独立，默认0，仅STOP允许设置。先在内存生效，用`$save <id>`断电保存。保持时先X，再修改参数。

格式：查询`H<id>`；设置`H<id> <0或1>`。

示例：`H1 1` → `H1 OK`；`H1` → `H1 1`。

到位条件：角度误差≤0.5°、实测滤波速度≤1°/s，连续满足200ms。H=0退出PID、输出中立并进入STOP/NONE，之后推偏不纠正；H=1继续PID纠偏，保持RUN/POS，直到新运动命令、X或保护停止。AS5600的反馈/到位速度采用100ms时间常数滤波，以抑制静止附近量化尖峰；阈值与滤波参数集中在arm_config.h，PID和限位制动保留原快速速度估计，需实机验证动态响应。

新的有效运动指令覆盖对应轴的旧指令，不同角度目标重置到位计时；相同目标在运行中重复发送不重置轨迹和计时。查询/非法命令不覆盖目标，单轴指令不替换另一轴目标。

## `$zero`

作用：把当前有效编码器读数设为零位，先保存在内存；不设置方向，需用`$save`保存。

格式：`$zero <id>`

示例：`$zero 1` → `$zero 1 OK`

## `$save`

作用：将指定关节的配置保存到Flash，断电后保留。A/P/H设置及zero/save在运行中拒绝执行。

格式：`$save <id>`

示例：`$save 1` → `$save 1 OK`

## `$clear`

作用：在标定、传感器和角度条件有效后清除故障，回到停止状态，不恢复旧运动目标。

格式：`$clear <id>`

示例：`$clear 1` → `$clear 1 OK`

## `$raw`

作用：查询原始传感器及标定标志，不改变配置。响应依次为编码器原始值、电流ADC、温度ADC、零位有效标志、中立值有效标志；原始值−1表示不可用，标志0为未设置、1为已设置。

格式：`$raw <id>`

示例：`$raw 1` → `$raw 1 1961 3611 4095 0 1`

## `$bus`

作用：通过USB查询当前连接板的UART总线累计计数，上电清零，不转发到其他板、不控制电机。rx为接收字节数，frame为CRC及封装有效帧数，bad为完整行的CRC或封装错误数，hit在slave上为寻址本板或接受的广播帧数、在master上为序号匹配的回包数，tx为UART发送并等待完成成功的帧数，txerr为发送失败数。wait为master最近等待的请求序号（slave为0），seen为最近解码成功的接收帧序号，mismatch为master收到有效帧但序号不匹配的次数。tx成功不代表对端已收到，查询时可能正有事务进行，wait与seen不要求始终相等。

格式：`$bus`

示例：`$bus` → `$bus rx=280 frame=20 bad=0 hit=20 tx=20 txerr=0 wait=20 seen=20 mismatch=0`

## `$busraw`

作用：通过USB查询本板UART最近收到的最多96字节，以十六进制按接收顺序输出；可能从一帧中间开始。用于排查有字节却无有效帧的情况，不控制电机、不清空UART或计数，无接收数据时返回EMPTY。

格式：`$busraw`

示例：`$busraw` → `$busraw 403432205232202A443836330A`，代表原始字节对应的文本`@42 R2 *D863`及换行。

## 总线与配置升级

上位机USB命令如上；内部UART沿用CRC/序号封装，角度帧正文如`R 30.5 -20.25`，不附有效期；PWM如`U 1510 1490 93`，最后的整数为扣除排队和线传时间后的剩余毫秒数。H查询/设置同样按关节转发。

主板后台持续轮询从板，主动状态查询也获取从板新回包，上位机不需要为角度目标续期。从板离线仅更新R2失联状态，不停止关节1或发送失联广播X；从板重连也不覆盖关节1目标。主轴不启用依赖从板回包的看门狗。slave有效且寻址本板或合法广播的总线帧刷新自身100ms看门狗，失联后回中立并清除目标，通信恢复不恢复旧动作。已在线从板返回真实故障时仍保留现有整机故障联锁。本地编码器异常、限位和控制循环异常保护继续有效。仅断开上位机USB不会取消角度动作或保持；U仍受自身100ms期限限制。

旧schema=2的标定和浮点PID配置可直接读取，新增H默认0；显式save后写入schema=3。上电只恢复配置，不恢复运动目标。升级前应保存标定记录，主从板及工具均升级0.5，旧版状态行不被0.5主板接受。

旧schema=2/3中neutral_valid=0的配置在初始化时采用1500µs并启用默认中立，保留原零位和方向；只更新内存，save后才写回Flash。neutral_valid表示存在生效配置，不能作为已经实测停转的证明。

J查询和设置均返回CMD。限速、加速度与中立的初始值由include/arm_config.h中的ARM_DEFAULT_VMAX、ARM_DEFAULT_AMAX、ARM_PWM_NEUTRAL提供；已保存的配置继续读取，NVS布局不变，不新增替代串口命令。
